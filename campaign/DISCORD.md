# Discord Announcement Templates

## Main Announcement (your server / #announcements)

```
[BOOK TITLE]

[2-3 sentence description of the book]

[TAGLINE]

Amazon: [AMAZON LINK]
See how it was made: [PROCESS LINK]

[ONE LINE ABOUT HOW IT WAS MADE]
```

## Short Drop (casual channels / other servers)

```
Wrote a [GENRE] book using [TOOL/METHOD]. [NUMBER] [CHAPTERS/SCENES] about [TOPIC]. Available on Amazon.
[AMAZON LINK]
```

## For Tech Discords

```
Built something different — a [GENRE] book, co-written with [TOOL], running on [YOUR SETUP]. [RAW MATERIAL] → [TOOL] shaping → published prose.

The pipeline is open source: [PROCESS LINK]
The book: [AMAZON LINK]

If a [YOUR JOB] in [YOUR TOWN] can publish a book on [YOUR SETUP], the tooling is ready.
```

## For Writing/Book Discords

```
Just published my first book — [GENRE], [UNIQUE CONSTRAINT].

The process: I [RAW METHOD] and [TOOL] helped shape them into prose. On [YOUR SETUP]. In [YOUR LOCATION].

"[BOOK TITLE]" — [ONE-LINE DESCRIPTION]

[AMAZON LINK]
```

## Tips
- Don't spam multiple channels in the same server
- Read the room — some servers don't allow self-promo
- Ask mods first if unsure
- Contribute to the community before you drop a link
- Pin your announcement in your own server
