# Case Study: Timeline

## The Book
**Title:** You Probably Think This Book Is About You
**Author:** Shane Brazelton
**Co-built with:** Claude (Anthropic)
**Genre:** Noir vignettes
**Length:** ~12,800 words / 22 scenes
**Published:** Amazon KDP (paperback + ebook)

## The Timeline

| Date | Milestone |
|------|-----------|
| Late 2025 | First voice memos recorded while driving |
| Jan 2026 | First scenes shaped with Claude |
| Feb 2026 | Full manuscript complete — 22 scenes, 4 interludes |
| Feb 2026 | Audiobook v1 recorded with Piper TTS (78 minutes) |
| Mar 2026 | ElevenLabs audiobook recorded |
| Mar 2026 | Cover designed |
| Mar 2026 | Published on Amazon KDP |
| Mar 2026 | Volume Two writing begins |
| Mar 20, 2026 | Volume Two Side B: 11 tracks written in one session |
| Mar 20, 2026 | Public process repo launched |
| Mar 20, 2026 | Campaign playbook created |

## What Worked
- Voice-to-prose pipeline (authentic, fast, unique)
- Open-sourcing the process (builds trust, attracts tech audience)
- The "dispatcher in Alabama" story (genuine, memorable, shareable)
- Claude Code for rapid iteration (11 tracks in one session)

## What We'd Do Differently
- Build an email list BEFORE launch (we had zero)
- Record a book trailer (video outperforms text on every platform)
- Engage in writing communities weeks before launch, not day-of
- Set up Goodreads author profile earlier
